# Abide — Bible Panorama Heroes

19 original PNG assets: Hero 00 cover plus Heroes 01–18. Use manifest.json for exact mapping. Convert to WebP for production, preserve originals, use responsive landscape containers, and avoid cropping important subjects. Some originals are wider than 16:9 but not exactly 2:1; do not stretch. No text overlays on artwork.
